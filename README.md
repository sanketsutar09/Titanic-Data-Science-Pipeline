# Yuva Internship - Data Science & Analytics

This repository contains all work, notebooks, datasets, and weekly analysis reports completed during the **Yuva Internship Program**.

---

## 📌 Project Overview

The project focuses on end-to-end Data Analysis, Exploratory Data Analysis (EDA), Data Visualization, and Statistical Hypothesis Testing using the classic **Titanic Dataset**.

### 🛠️ Skills & Technologies Used
- **Language**: Python
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, SciPy
- **Tools**: Jupyter Notebook, VS Code
- **Methodologies**: Data Cleaning, Feature Engineering, EDA, Data Storytelling, Statistical Analysis & Hypothesis Testing (t-test, Chi-square test, ANOVA).

## 🚀 Key Highlights & Weekly Summary

- **Week 1: Data Cleaning & Exploratory Data Analysis (EDA)**
  - Preprocessing missing values (Age, Cabin, Embarked).
  - Outlier detection, distribution analysis, and initial data insights.
- **Week 2: Data Visualization & Data Storytelling**
  - Univariate, bivariate, and multivariate analysis.
  - Interactive & publication-ready visualizations using Seaborn and Matplotlib.
- **Week 3: Hypothesis Testing & Statistical Insights**
  - Parametric and non-parametric hypothesis testing (Independent t-tests, Chi-Square tests of independence, ANOVA).
  - Validating key analytical questions regarding passenger demographics and survival rates.

## ⚙️ Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Set up virtual environment (optional):**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install pandas numpy matplotlib seaborn scipy notebook
   ```

4. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
